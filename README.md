# BloodConnect — Trichy Blood Donation Network

BCA final-year project using HTML, CSS, JavaScript, Python Flask and SQLite.

Features:
- Donor registration and login
- Blood request creation
- Search donors by blood group, district and area
- Donor availability
- Nearby hospital directory
- Donation camp directory
- Emergency request dashboard
- AI-style request classification and urgency scoring
- Admin-ready database structure

Run:
1. Install Python 3.10+
2. Double click run.bat
3. Open http://127.0.0.1:5000

Note: Hospital and blood availability shown in this student project are demo/sample records unless connected to a verified hospital/blood-bank data source. Do not rely on sample availability for a medical emergency.
